Pick a component while browsing; it is sent to your panel as a capture record. Nothing else on the page is read, and nothing goes anywhere but the address below.

Where your panel server is listening. Anything other than the default needs one permission grant, which Chrome asks for when you save.

Printed by the server on first start, and in pairing-token.txt on the panel's data volume. It is stored on this machine only -- never in your Chrome profile sync.

Buffer

Captures are queued here first and sent in the order they were taken. When the panel is unreachable they wait -- across a browser restart -- and the toolbar badge shows how many.

    What this extension reads and sends

    • Reads the computed style values of the one element you click, its size and position, and the page URL. Never the page's markup, text, stylesheets, cookies or storage.
    • Captures a screenshot of that element's box, cropped from the visible tab, in the extension itself -- the page never sees the image.
    • Sends both to the panel address above, and to nothing else. There is no telemetry.
    • Stores the panel address, the pairing token and captures still waiting to be sent, all in this browser's local extension storage.
    • Runs only on the tab where you clicked the toolbar button, and only from that click onwards.
